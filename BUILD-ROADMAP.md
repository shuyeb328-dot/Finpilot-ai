# Build Roadmap

## Phase 1 — Foundation
Authentication, dashboard, database, Master AI orchestration, secure secret handling, basic manual finance data.

## Phase 2 — Intelligence
Web retrieval, source verification, financial knowledge/RAG, market-data adapters, probability/risk engine.

## Phase 3 — Voice
Realtime voice session, speech recognition, finance intent routing, spoken responses, confirmation flows.

## Phase 4 — India connectivity
Consent-driven Account Aggregator integration through appropriate regulated participants/providers; never collect bank passwords.

## Phase 5 — Production
Security hardening, observability, compliance review, load testing, billing, app-store release.
