# Live Intelligence

FinPilot supports server-side provider adapters. SEC EDGAR's public data APIs expose company submissions and XBRL facts without API keys and are updated throughout the day. Alpha Vantage provides market/news/crypto/forex/fundamental endpoints when its server-side API key is configured.

All provider results are evidence inputs, not automatic truth. The verification layer must classify primary, corroborated, developing, contradicted, or unverified claims before high-impact approval.
