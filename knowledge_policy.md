# Knowledge + Continuous Improvement

1. Prefer primary/authoritative sources for regulations and financial facts.
2. Timestamp every time-sensitive fact.
3. Store source URL/reference and jurisdiction.
4. Detect conflicts between sources.
5. Never silently overwrite verified knowledge.
6. Version knowledge entries.
7. Evaluate proposed updates before promotion.
8. User feedback may improve ranking/prompts/evaluations, but must not automatically rewrite financial facts.
9. Keep current web retrieval separate from durable knowledge.
