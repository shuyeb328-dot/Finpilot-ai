# Probability / Risk Engine

For each scenario, return:
- probability_positive
- probability_neutral
- probability_negative
- expected_return
- expected_downside
- risk_reward_ratio
- max_reasonable_drawdown
- confidence
- data_timestamp
- model_version
- source_set

Never manufacture a probability when sufficient data/model assumptions are unavailable. Clearly label estimates as model outputs. Include sensitivity analysis and scenario assumptions.
