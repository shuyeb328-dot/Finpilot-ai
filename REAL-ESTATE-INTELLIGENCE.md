# Real-Estate Intelligence

## Coverage
- Residential, commercial, industrial, retail, office and land
- REITs and listed property vehicles
- Rental and lease economics
- Purchase versus rent analysis
- Mortgage/financing scenarios
- Cap rate, NOI, DSCR and cash-on-cash return
- IRR/NPV and equity multiple
- Vacancy, rent-growth and expense assumptions
- Property taxes, insurance, maintenance and capex
- Development and construction scenarios
- Location and market-cycle analysis
- Comparable-property analysis
- Liquidity and exit-risk analysis
- Tenant concentration and lease rollover
- Regulatory/zoning/title due-diligence checklists

## Property decision model
`purchase price + transaction costs + financing + operating costs + vacancy + taxes + capex + expected rent + exit value`

The system should clearly separate verified facts, user assumptions, estimates and forecasts. Property-level legal/title/tax decisions require qualified local professionals.
