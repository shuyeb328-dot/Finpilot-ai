# FinPilot AI v1000

Top-tier financial decision intelligence foundation for personal and company finance.

## Run
```bash
npm test
npm run smoke
npm run verify
npm start
```

Set `OWNER_ID` and `OWNER_TOKEN` for protected API access. Keep provider/LLM keys in server-side environment variables only.

See `docs/V1000.md` and `config/V1000-COVERAGE.md`.
